# Oz Home Energy website asset pack

The owner has confirmed that every asset in this pack is authorised and ready for website use. This statement records the owner's confirmation; it is not independent verification by the preparer.

## Instructions for Claude

1. Import this complete folder into the existing Oz Home Energy website repository.
2. Preserve these master files. Create separate optimised web derivatives rather than overwriting them.
3. Generate responsive WebP or AVIF versions with sensible JPEG/PNG fallbacks.
4. Remove screenshot black borders where present, correct orientation and crop carefully without cutting off equipment.
5. Use factual alt text based only on what is visible. Do not invent locations, capacities, brands that are not visible, savings, results, customer identities or project specifications.
6. Do not show every asset on the homepage. Curate the strongest image for each section and use the remainder in relevant service pages or project galleries.
7. Treat `10-installation-process` as progress/commissioning imagery. Do not label open equipment or unfinished switchboards as completed installations.
8. Keep the existing Oz Home Energy design system: `#0540C1`, charcoal and Montserrat.
9. Validate image loading, mobile crops, aspect ratios, layout stability, accessibility, performance and broken paths.
10. Work on a new branch, create a pull request, run the complete QA suite and do not merge.
