Grid connection

Endeavour Energy network

Penrith properties connect to the grid via Endeavour Energy, a different distributor to Ausgrid, which covers most of inner Sydney. The solar connection application process, metering and export limit rules differ between the two networks. We handle the Endeavour Energy application as part of every installation we carry out in this area, so you don't need to navigate it yourself.
